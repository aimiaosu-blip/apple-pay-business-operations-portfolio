# Metric Glossary

- **Transaction success rate** = successful transactions / transaction attempts. Denominator includes all modeled authorization attempts in the selected window.
- **Failure rate** = failed transactions / attempts = 1 − success rate.
- **Synthetic GMV** = sum of modeled successful transaction value; not revenue.
- **Activation rate** = activated devices / eligible devices in a weekly cohort.
- **First-transaction rate** = devices with a first transaction / activated devices.
- **30-day repeat rate** = devices with a repeat transaction within 30 days / devices with a first transaction.

Cadence: transaction health weekly and monthly; funnel metrics by eligibility cohort. Timezone is treated as China Standard Time (UTC+8) at calendar-day grain. Partial periods should not be compared with complete periods.
