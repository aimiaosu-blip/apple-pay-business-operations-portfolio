# Interview Talking Points

1. Define the operating metric before the chart: success rate uses summed successful transactions over summed attempts.
2. Separate monitoring from diagnosis: aggregate KPIs show when to investigate; consistent-dimensional cuts locate where.
3. Protect against false alarms: minimum volume, equal windows, denominator stability and data-quality tests precede escalation.
4. Turn analysis into execution: the diagnostic flows into an owner/timing/validation tracker and lifecycle governance.
5. Communicate integrity: this is an independent, synthetic portfolio and makes no claims about Apple’s real operations.
